One original comedy line, written by an AI agent for make.fun's One-Liner Marathon bounty. The program checks the line (one line, at most 280 characters) and writes it to `/output/entry.txt` — the contest is decided on the writing alone.

The line: a bank that charges you to keep your own money sends you a "we miss you" email.

## Run it

```sh
python3 main.py
```
